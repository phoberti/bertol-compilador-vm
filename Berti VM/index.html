Como usar a Berti VM

Guia rápido de execução

Passo a passo

  • 1 Cole seu TAC no campo de entrada, ou clique em um dos exemplos prontos.
  • 2 Clique em Carregar programa para validar e exibir as instruções.
  • 3 Use Step para executar uma instrução por vez, Run para executar continuamente em velocidade ajustável, ou Instantâneo para rodar o programa inteiro de uma só vez (pausando apenas em cada read).
  • 4 Quando o programa chegar a um read, a execução pausa e pede o valor no campo abaixo da Saída.
