1. Nome da Linguagem: BERTOL
--------------------------------------------------------------------------------------------------------

--------------------------------------------------------------------------------------------------------
2. Tipos de Dados Primitivos Suportados:

    - int     (INTEIRO)  -> Números inteiros.
    - float   (DECIMAL)  -> Números reais.
    - string  (TEXTO)    -> Textos.
    - boolean (LOGICO)   -> Verdadeiro ou Falso.
--------------------------------------------------------------------------------------------------------

--------------------------------------------------------------------------------------------------------

    C. Operadores Aritméticos:

--------------------------------------------------------------------------------------------------------

--------------------------------------------------------------------------------------------------------
4. Formação dos Identificadores (Regra para Nomes de Variáveis):

    - Expressão Regular : [a-zA-Z]([a-zA-Z0-9_])*
    - Tamanho Mínimo    : 1 caractere.
    - Tamanho Máximo    : 30 caracteres.
    - Não podem ser palavras reservadas.
    - Case Sensitive.

    EXEMPLOS:
        - Declaração              : nomeVariavel[TIPO]#
        - Declaração e Atribuição : nomeVariavel[TIPO] VALE valor#
        - Atribuição              : nomeVariavel VALE valor#
--------------------------------------------------------------------------------------------------------

--------------------------------------------------------------------------------------------------------
5. Comandos de Entrada e Saída:

    - Entrada : RECEBE   -> RECEBE[identificador]#
    - Saída   : MOSTRA   -> MOSTRA[lista de valores]#
--------------------------------------------------------------------------------------------------------

6. Estruturas Suportadas pela Linguagem e seus Respectivos Comandos:

    - Estrutura de Decisão (SE - SENAO):

        SE(condicao) {
            ...
        }
        SENAO {
            ...
        }

    - Laço de Repetição Condicional (ENQUANTO):

        ENQUANTO(condicao) {
            ...
        }

    - Laço de Repetição Contado (PARA):

        PARA identificador DE inicio ATE fim PASSO valor {
            ...
        }

9. Estrutura Geral do Programa (Sintaxe):

-----------------------------------------------
EXEMPLO 1: Declaração, entrada, decisão e laço
-----------------------------------------------
@@ Declaração de Variáveis
limite[INTEIRO] VALE 0#
contador[INTEIRO]#

@@ Entrada e Saída de Dados
MOSTRA["Informe um valor: "]#
RECEBE[limite]#

@@ Estrutura Condicional
SE(limite MAIOR 0){

    @@ Laço de Repeticao Contado
    PARA contador DE 0 ATE limite PASSO 1 {
        MOSTRA[contador]#
    }
}
SENAO {
    MOSTRA["O limite deve ser maior que 0."]#
}

-----------------------------------------------
EXEMPLO 2: Expressões aritméticas
-----------------------------------------------
numA[INTEIRO]#
numB[INTEIRO]#
numC[DECIMAL]#
resultado[DECIMAL]#

RECEBE[numA]#
RECEBE[numB]#
RECEBE[numC]#

@@ Expressão aritmética
resultado VALE ((numA ADD numB) SUB (numC DIV 2))#

MOSTRA["O resultado vale: ", resultado]#

SE(resultado MAG 0) {
    MOSTRA["O resultado é maior ou igual a zero."]#
}
SENAO {
    MOSTRA["O resultado é menor que zero."]#
}
